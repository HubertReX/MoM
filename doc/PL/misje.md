## PL

```dataview
TABLE WITHOUT ID
  file.link as "Quest",
  file.inlinks as "Depending on this",
  file.outlinks as "this depends on",
  file.aliases as "AKA"
FROM ""
WHERE file.folder = "PL/Misje"
SORT file.aliases ASC, file ASC
```
